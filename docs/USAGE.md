# 操作ガイド — Diffusion Lab 1.0

フルカラーLEDテープと拡散板の距離、LED配置、形状、材料を比較するブラウザアプリです。

**実測校正前の設計比較モデルです。実製品の見え方・測光値を保証するシミュレータではありません。** LEDの型番を選び、資料値・近似値・仮定値を確認しながら、材料色とは別に光度・透過・拡散の条件を設定します。

## 起動

`index.html` を通常のブラウザで開きます。インストール、ビルド、アカウント、外部ライブラリは不要です。JavaScript と Web Worker が利用できるデスクトップブラウザを想定しています。スマートフォン向けの折りたたみ設定画面もあります。

ローカルファイルの実行が管理ポリシーなどで制限される環境では、このフォルダーで次を実行し、表示されたローカルアドレスを開きます。

```sh
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

このHTMLは単独で動作するため、`index.html` のまま静的ホスティングにも配置できます。

## 最初の操作

「計算する形状」は初期状態で「平面」です。従来のパネル・SVG輪郭・テープ位置調整は平面で使います。

1. 左上のサンプルから「LEDの粒を見る」または「面の均一さを見る」を選びます。
2. 幅・高さ、密度、列間隔、LED型番・テープ幅、材料を入力します。左の設定欄は独立してスクロールします。
3. 正面表示の下で距離を変更し、「6つの距離を計算」で 2.5 / 5 / 10 / 20 / 40 / 80 mm を比較します。

距離を変えても露出は自動調整しません。「露出を1回調整」はその瞬間だけ調整する操作です。暗くなりすぎるときは表示露出を調整できますが、異なる距離を比較する間は同じ露出にしてください。

## 中心で折り返したLEDテープと円筒

1. 「計算する形状」を「円筒（中心で1本を折り返す）」へ切り替えます。
2. 円筒の**内径**、軸方向の長さ、折り返した後のテープの**片側の長さ**、2面の発光方向を入力します。初期値は内径80 mm・軸長200 mm・片側長160 mm・方向0°です。実物に合わせて変更してください。
3. LED密度、テープ基板の実測幅、LED型番・光度、材料を設定します。円筒は乳白・強拡散の近似なので、**拡散成分100%**が必要です。低い拡散成分を使うと、適用範囲外の説明を表示します。
4. 「仕上がり」を2Dまたは3Dで確認します。「LED配置」では軸に沿う折り返しテープを断面・側面で確認します。
5. 内径や向きを変更し、「比較基準に保存」を使って同じ露出で比べます。円筒のLEDから内面までの距離は内径の半分です。平面用の6距離比較は円筒では使いません。

内径・軸長は10〜2,000 mm、片側テープ長は1〜2,000 mm、発光方向は−180〜180°です。片側長は円筒の軸長以下で、基板端部・LED外形を収められる長さが必要です。テープ幅とLED代表外形幅は内径より小さくしてください。密度から求めた両面のLED合計は5,000個までです。

1本のテープを円筒の中心軸に沿って折り返す構成です。配線順は、片側を軸座標の負側から正側へ進み、折り返して反対側を正側から負側へ戻ります。片側のLED数をNとすると、**2N個を1本の連続した配線**として点灯します。両側を別々のテープや同じ順番の独立配線として扱いません。片側の長さは折り返し後の値なので、折る前のテープ長の目安はその2倍です。

2面の発光方向は指定角度と、その反対側の角度です。方向0°なら0°と180°へ発光します。各側のLEDを中心軸上に重ねた点光源として計算するため、テープの幅・LED外形・折り返しの曲げ半径から、実際の両面間隔を自動算出しません。幅と外形は配置寸法の確認と模式表示に使います。

2Dの横軸は円周の0〜360°、縦軸は軸方向の長さです。左右端は円筒の同じ継ぎ目につながります。3Dはこの外面の計算結果を円筒へ貼り付けた表示で、ドラッグで視点、ホイールで倍率を変えられます。両表示は同じ光学計算を使います。「光量マップ」と平均・均一度も円筒外面の結果です。

ゲーミング点灯・出力調整、JSON保存・読み込み、停止時のPNG・CSVにも対応します。円筒CSVは円周角度と軸方向の座標で出力します。平面へ戻ると、保存していた平面の輪郭、X/Y座標、テープ接続を引き続き使えます。円筒では平面テープのドラッグ・回転・整列・本数変更を行いません。

**円筒モードの限界**：点光源・拡散成分100%の比較モデルです。内面の反射、支柱やテープによる遮蔽、折り返しの曲げ半径、実際の両面間隔、透明・弱拡散材の直接像を再現しません。実物の固定・配線・切断単位・発熱を保証する寸法設計機能ではありません。

| 輪郭 | 長方形、角丸長方形、円・楕円、円環・楕円環、多角形、SVGパス |

| 距離 | LED発光面から拡散板裏面まで 0.25〜300 mm |

| LED | WS2812B / WS2812B-MINI / WS2812C-2020 / SK6812（RGB） / SK6812-MINI / カスタム。有効発光幅・角度・RGB光度は上書き可能 |
| 光学特性 | RGB正面光度、半値角全幅、RGBダイ分離の有無 |

LED数は最大5,000個です。自動配置の候補数にも計算負荷を抑える上限があります。配光は全RGB共通です。パターンは配線順に適用され、並列テープは蛇行順で採番します。

平面の自由な多角形の座標はパーセントです。左上を `0,0`、右下を `100,100` とし、外周に沿った順に1行1点で入力します。自己交差や、任意形状の穴は非対応です。円環の穴は専用形状で表せます。

自由なテープ経路は mm 単位です。原点は中央、x は右、y は下。「画面で経路を描く」でクリック追加し、Enter または「確定」で終了します。Escapeで取り消します。曲線を実装したい場合は細かい折れ線に分けます。

### SVGから板の輪郭を取り込む

1. 「ベース・拡散板の輪郭」の形状を「SVGパスの輪郭」にします。
2. 「SVGファイルを開く」で `.svg` を読み込むか、「SVG全文 または pathのd属性」にSVG文書・`d` の文字列を貼り付けます。
3. 「全パスを輪郭に適用」を押します。**全path要素の塗り領域をまとめて**、1つの板の形状として取り込みます。
4. 幅・高さ（mm）で実際の寸法を指定します。

重なったパスは領域の和集合として扱い、重複線を板の端にはしません。離れた部分も取り込み、空白部分と穴にはLEDを自動配置せず、光学計算の評価領域にも含めません。外周配置では実際の境界ごとにテープを分け、幅を含めて安全に収まらない部分も分割します。並列配置でも、LEDテープ全体を動かすルールは維持されます。

パスの直線・3次/2次ベジェ曲線・円弧、絶対/相対座標に対応します。pathと親グループの `transform` 属性（移動・拡縮・回転・行列・傾斜）を反映します。SVGの余白・viewBox全体ではなく、変換後の全パスの外接範囲を板の幅・高さへ対応づけます。SVGのpxやmmの指定から実寸を自動決定する機能ではありません。

「取り込み時に縦横比を保つ」は初期状態でONです。現在の幅に合わせて高さを設定し、必要なら10〜2,000 mmの寸法範囲に合わせて全体を縮尺します。OFFなら現在の幅・高さに合わせて伸縮します。取り込んだ後の幅・高さはそれぞれ編集でき、チェックは次回取り込み時にだけ適用されます。

穴の扱いは `fill-rule` に従います。「SVGの指定を使う」は各パスと親の属性・インラインスタイルを読みます。`evenodd` は入れ子で塗りと穴を交互にし、`nonzero` はパスの向きも考慮します。スタイルシート内の `fill-rule` は未対応なので、表示される案内に従って塗り規則を明示指定してください。パスを別々に塗った領域の和集合なので、別のpath要素として描いた図形を穴の指定には使えません。穴は同じpath内のサブパスにしてください。

曲線は細かな線分へ近似します。輪郭は合計2,048頂点まで、各pathは1,024命令・100,000文字まで、ファイルは2 MB・100パスまでです。開いたパスはSVGの塗りと同じように始点・終点を直線で閉じます。複雑すぎる輪郭や不正なデータは、適用済みの形状を変更せずにエラーを表示します。

図形・文字はSVG編集ソフトでパスへ変換してください。線幅、画像、クリッピング、マスク、装飾、defs内の定義、use参照、入れ子のsvg、CSSによる変形、内部DTD・ENTITY定義を含む文書には未対応です。SVGの描画全体を再現する機能ではなく、pathの塗り領域を輪郭にする機能です。

取り込み結果は設定JSONとブラウザの自動保存へ含まれます。元のSVGファイルを再度選ばなくても復元できます。元のSVG全文・d属性は設定JSONに含めません。一般的なSVG 1.1の外部DOCTYPEは宣言だけを取り除き、参照先を読み込みません。

### テープ幅と輪郭内の配置

「LEDテープ・配置」の「LEDテープの幅（mm）」に、実物の基板の幅を入力します。範囲は0.1〜100 mmです。**新規設定の8 mmは仮値で、特定の製品仕様ではありません。** LED型番からテープ幅は決まらないため、型番選択や型番初期値への復元でも入力した幅は保持します。有効発光幅・LED外形幅とは別の値です。

基板は各LEDの周辺をテープ幅×テープ幅の回転した正方形、隣接LED間をテープ幅の長方形として扱います。LED本体は資料に基づく代表外形幅の正方形です。2D配置図、3D表示、輪郭内の判定で同じ幅と形状を使います。基板がLED本体より細くても、LEDの回転した角まで収まる必要があります。

長方形・角丸・楕円・円環、多角形、SVGの輪郭に対して、端部と接続区間の面全体を確認します。多角形・SVGは連続した境界線分で判定するため、LED中心だけが収まっていても、細い切り欠きを横断したり、接続区間が穴を完全に覆ったりする配置は受け付けません。SVGの曲線そのものは取り込み時の線分近似です。

並列・グリッド・円周・外周の自動配置では、幅やLED外形が収まらない候補を除き、切り欠き・穴を跨ぐ接続区間を別のテープへ分けます。除いたLEDの前後を新たに接続して穴を跨ぐことはありません。画面には実際の本数と必要な分割箇所数を表示します。SVGや多角形の外周は各境界を局所的に内側へずらしますが、厳密なCADのオフセット処理ではなく、幅が収まらないところを分割する方式です。

自分で指定した折れ線経路は自動分割しません。元の折れ線と、密度から決めたLED間の接続の両方を幅込みで検証し、不適合なら適用前の経路を保持します。「画面で経路を描く」の確定が失敗した場合も描画中の点は残るので、調整して再度確定するかEscapeで取り消してください。

曲げ半径、切断単位、コネクタ、電線の取り回しはモデル化していません。**分割した各テープ間の電線接続は自動追加しません。** 表示上の各本を、実物でどう切断・固定・接続するかは別途確認してください。

### テープ全体の位置調整

1. 「LED配置」タブを開きます。
2. 画面上のLEDまたは接続部分をクリックするか、左の「編集するLEDテープ」で選びます。選択したテープ全体が緑色で強調されます。
3. ドラッグして移動します。または「先頭LEDのX」「先頭LEDのY」を入力し、「X・Yの位置を適用」かEnterを押します。

画面でテープを選択した後、矢印キーで1 mmずつ移動できます。Shiftを押しながらなら10 mm、Ctrlなら0.1 mmです。上はYの負、下はYの正へ動きます。入力欄・一覧・テキスト編集・ヘルプ表示中にはテープを動かさず、各コントロールの通常操作を保ちます。一覧から選んだ場合は配置画面をクリックしてから矢印キーを使います。輪郭外へ出る移動は反映しません。

座標はmm単位です。板の中心が `0,0`、右方向がXの正、下方向がYの正です。基準点は**テープの配線順で先頭のLED中心**で、テープの中心ではありません。並列テープは行ごとに配線方向が反転するため、2行目の先頭は右側になります。

動く単位は接続されたテープ全体です。LED同士の間隔、並び、発光面の向き、点灯パターンの順番は保持し、ほかのテープは動かしません。並列配置は基本的に各行を1本、蛇行グリッド・通常の外周・円環は連続して収まる候補を1本として扱います。凹形・穴・離れた輪郭では必要に応じて分割するため、実際の本数は増える場合があります。SVGの外周は境界ごとに別のテープです。自由経路は幅込みで収まる1本として扱います。曲げ方やLED間隔を変更する操作ではありません。

自動配置を初めて動かすと「テープ位置を個別に調整」に切り替わり、全テープの接続・座標を固定します。密度や経路を作り直す場合は自動配置に戻してください。位置調整モードの「直前の自動配置をコピー」は直近の自動配置へ戻し、「全テープを削除」は配置を空にします。

基板の端部、回転したLEDパッケージ、LED間の幅のある接続まで輪郭内に収まる移動だけを受け付けます。範囲外の座標入力では配置を変更しません。ドラッグ中は最後に収まった位置で止まり、離すとその位置を確定して再計算します。Escapeまたはポインター操作の中断で、ドラッグ前の位置に戻ります。空白のクリックで独立したLEDを追加する操作はありません。

接続情報は設定JSONとブラウザの自動保存に含まれます。旧JSONの個別配置は接続の区切りが不明なため、読み込んだLED群を1本として扱います。板の輪郭・寸法・幅を後から変更しても、各LEDを個別に丸めず座標と接続を保ちます。幅や接続が収まらなくなったテープは配置図で基板を赤く表示し、**そのテープ全体を光学計算から除外**して警告します。3Dにも表示しません。移動・回転やテープ幅の調整で収まるようにすると再び計算対象になります。

位置調整時の基準ピッチと距離比は密度入力からの基準値です。実際のテープ間隔や曲がった経路の各LED間距離を意味しません。

### テープの本数・角度・整列

「LEDテープの本数」に1〜100の整数を入力し、「本数を適用」またはEnterを押します。並列の自動配置では指定本数を中央に並べます。必要に応じて列間隔を狭めますが、LED同士のピッチは変えません。本数を指定していない自動設定は板の高さと列間隔から候補を決め、画面には幅込みの判定・必要な分割後の実際の本数を表示します。

並列配置で指定した本数と、切り欠き・穴を避けるために必要な分割後の本数が一致しない場合はエラーを表示します。「本数を自動に戻す」で必要な分割を受け入れてください。その後「テープ位置を個別に調整」へ切り替え、各本を調整できます。指定本数を保つために切り欠き・穴を跨ぐことはありません。

位置調整など他の配置では、選択したテープ（未選択なら最後のテープ）を接続・形状・角度ごと複製して空いている場所へ置きます。元のテープは動かしません。本数を減らすと末尾のテープから丸ごと削除します。基板・LED・接続が輪郭内に収まり、ほかのテープの外接範囲と重ならず置く場所がない場合は配置を変更せず案内します。複雑な折れ線の空き場所判定はテープの外接範囲を使うため、手で調整すれば入る場合でも複製が断られることがあります。

「LED配置」タブでテープを選び、「テープの角度」を入力して適用します。範囲は−180〜180°、0°は右向き。角度は配線順の先頭LEDの向きです。**選択テープのLED中心の平均位置を軸に**剛体として回転し、折れた経路も接続・間隔・各LEDの相対的な向きを維持します。X/Yは回転後の先頭LEDの位置へ更新されます。

画面上のLEDや接続部分を**ダブルクリック**すると回転モードになります。「画面で回転する」ボタンでも切り替えられます。紫色の中心・円ガイド・ハンドルが表示され、選択テープまたはハンドルをドラッグすると1°単位で回転します。Shiftを押すと15°刻みです。角度欄から数値で設定する操作も使えます。範囲外では最後に収まった角度で止まり、ドロップで確定します。Escape・ポインター中断はドラッグ前へ戻します。「移動モードに戻る」で通常のドラッグへ切り替えます。回転モードでも矢印キーは位置を動かします。

整列は「選択したテープ」または「配置全体」を選び、左・左右中央・右・上・上下中央・下を押します。**上下中央は縦方向の中央揃え**です。テープ基板・回転したLEDパッケージ・接続区間を含む外接範囲を板の外形に合わせ、端揃えは「端からの余白」を使います。配置全体では全テープを同じ量だけ移動し、テープ同士の間隔も保ちます。SVG・円環などは穴も考慮し、端部や接続区間まで輪郭内に収まらない回転・整列を反映しません。複数本を動かす場合も操作全体を取り消し、元の座標・接続を保持します。

### 仕上がりを3Dで表示する

「仕上がり」タブの「表示」を2Dから3Dへ切り替えます。平面ではベース、LED発光面、LEDから板裏面までの距離、拡散板の厚さを同じmm座標の立体で描画します。円環・SVGの穴や離れた輪郭も表示できます。「LEDテープを表示」で下側のテープとLED表示を切り替えます。テープ底面は土台上面へ接触し、パッケージはテープ上面へ載ります。基板とパッケージの側面も描画します。テープは入力したテープ幅で描き、手動配置の不適合群は表示しません。基板・パッケージの高さは製品仕様ではなく模式的な値です。板に隠れる部分は見えません。円筒では外面の360°計算結果を内径・厚さ・軸長に対応する円筒へ投影します。

ドラッグで視点を回し、ホイールで拡大・縮小します。操作欄の「向き」「傾き」「倍率」でも調整でき、「視点をリセット」で初期の向き−25°・傾き55°・倍率1へ戻します。ドラッグ中のEscapeやポインター中断は視点を戻します。視点は設定JSONと自動保存に含まれ、3D表示中のPNGは同じ視点で書き出します。光量マップ・LED配置・小さな比較画像は2Dです。

3Dは**平面の正面画像、または円筒の外面展開画像を立体へ投影する表示**です。視点を変えても線形フィールド・均一さ・平均輝度は変わりません。斜め方向の実際の見え方や反射・屈折を再計算する機能ではありません。

### 動くRGB演出

点灯パターンを「ゲーミング（動くRGB演出）」へ切り替えます。演出を選ぶと光の重なりを準備して再生します。

| 演出 | 動き | 速度1倍の周期 |
|---|---|---|
| レインボーウェーブ | 配線順に虹色が流れる | 6秒 |
| RGBチェイス | 虹色の明るい部分が追いかける | 5秒 |
| 虹色ブリージング | 虹色が変化しながら呼吸点灯する | 8秒 |
| シアン・マゼンタパルス | 2色の波が配線順に動く | 4秒 |

速度は0.1〜3倍です。「停止」を押すとその点灯位置を指定精度（長辺160/288/448点）で直接計算します。再生位置のスライダーは演出1周期の0〜100%で、操作すると停止してその位置を計算します。0%と100%は同じ点灯です。「再生」で続けます。演出はテープ全体の配線順に適用し、テープごとに独立したタイマーを設定する機能ではありません。

再生は最大30fpsで、高速解像度の24位相を光学計算し、**線形の輝度・照度・LED出力を時間補間**します。画面の色を差し替える演出ではなく、光源の変化を反映した結果です。ただし時間・空間ともに近似なので、最終比較は停止して高精細でも確認してください。配置・距離・材料・演出を変えると準備をやり直します。露出・視点・速度だけの変更ではやり直しません。

再生・準備中のPNG・CSV・比較基準保存・露出の1回調整は停止まで無効になります。設定JSONは再生中でも保存でき、現在の点灯位置で**停止した設定**として復元します。「6つの距離を計算」は再生を停止し、6条件を同じ位相で比較します。計算・再生はブラウザ内で完結します。

## ARGB は透過率ではありません

`#AARRGGBB` 形式です。本アプリの A は「着色の強さ」であり、物理的な透過率・不透明度ではありません。

- `#00FF0000`：無着色として扱います。
- `#FFFF0000`：赤の透過色フィルタを完全適用します。
- `#FFFFFFFF`：無彩色の透過として扱います。透過率45%ならその光量に減衰し、透過率0%なら発光成分はゼロになります。

RGBは理想的なsRGBチャンネルのフィルタで、材料の実際の分光透過ではありません。拡散材料の色だけから、どの波長をどれだけ通すか、どの方向へ散乱するかは決定できないため、光学的なパラメータを分けています。

## プリセットの意味

材料プリセットはすべて仮定値です。実在製品の品番やメーカー測定値に対応させていません。「乳白アクリル風」「白色フォーム風」は挙動を比べるための出発点です。

新規起動のLEDはWS2812Bで、R=400 / G=1150 / B=250 mcdを使います。採用資料の光度範囲の中心をモデル用に採用した値で、メーカーの典型値ではありません。型番を選ぶとRGB正面光度も切り替わり、出力%とテープ幅はそのまま保持します。

| 型番 | 選択時のR / G / B（mcd） | 光度の根拠 |
|---|---:|---|
| WS2812B | 400 / 1150 / 250 | 資料のレンジ中心・16 mA |
| WS2812B-MINI | 310 / 780 / 215 | 資料の典型値・12 mA |
| WS2812C-2020 | 80 / 270 / 70 | 資料の典型値・5 mA |
| SK6812 | 397.5 / 1045 / 240 | 資料のレンジ中心・12 mA |
| SK6812-MINI | 397.5 / 1045 / 292.5 | 資料のレンジ中心・12 mA |

光度はルーメンではなく、正面方向の光の強さを示すmcdです。光学表の電流以外の測定条件は未記載で、電気特性や寿命試験の別表条件を光度へ転用しません。SK6812-012の資料にあるRGB同時点灯の70%条件は説明と警告で示しますが、出力の自動変更や追加の70%係数はありません。資料条件に合わせる場合は出力%を自分で設定してください。

型番選択ではRGB正面光度、外形の代表幅、有効発光幅、半値角全幅を設定し、LED外形の表示もONにします。配置図・正面の位置重ね・3Dパッケージの幅は現在の代表幅で描画します。型番一覧の5050系 / 3535系 / 2020系はサイズ区分で、代表幅は資料の外形・端子などを考慮した数値なので区分の公称辺長と同一ではありません。外形と有効発光面、テープ基板の幅は別の値です。テープ幅は型番から設定せず、入力値を保持します。「選択LEDの資料・近似について」で参照した仕様書の版・根拠・リンクを確認できます。
WS2812B / WS2812B-MINI の幅は機械図の開口を面積が等しい正方形に置き換えた近似で、実測の有効発光幅ではありません。
WS2812C-2020 / SK6812 / SK6812-MINI の幅は資料未記載のため仮定です。SK6812 / SK6812-MINI の半値角全幅120°は資料値で、Worldsemiの3種類の120°は資料未記載のため仮定です。

幅・角度・RGB光度を初期値と異なる値へ編集すると「手動上書き」と表示します。「型番の初期値に戻す」で有効発光幅・角度・外形・RGB光度を再適用し、出力%とテープ幅は保持します。外形の手入力は「カスタム・旧設定」で行います。
詳しい数値と計算方法は [LEDの仕様と近似](LED_SPECS.md) を参照してください。

同じサイズでも製品・世代・電流条件による性能差があるため、実製品比較では光度・有効発光幅・配光も入力してください。

## 表示と評価

「仕上がり」は sRGB と表示露出を用いた外観近似、「光量マップ」は画像ごとのP95を上限とした疑似色表示、「LED配置」は実装位置確認用です。

均一さは評価領域内の `P5 / P95` です。暗い側5%点と明るい側95%点を比べます。最低輝度・最低照度や色むらの合格基準ではありません。光がゼロの場合は未定義として `—` を表示します。

平均輝度は RGB 各成分を合計したモデル推定 cd/m² です。実測で校正していない限り、表示単位があっても実測同等の精度はありません。評価指標は露出・周囲光・トーンマッピング前の値です。

画面の推定光束（lm）は、現在の光度と`cos^m`配光を前方半球へ積分した光源のモデル値です。現在の出力%を反映したLED1個のRGB白点灯の参考値で、現在のパターンの色や全LEDの合計ではありません。拡散板に入る前の値であり、メーカー公称ルーメンや板の平均輝度（cd/m²）ではありません。板の透過率を変えても光源の光束自体は変わりません。SK6812のRGB全点灯・100%基準は約5.286 lm、70%へ設定した場合は約3.70 lmですが、いずれも製品の保証値ではありません。

端の除外で評価領域が残らないときは、警告とともに全面評価へ切り替えます。楕円の除外範囲は、長短半径を除外幅だけ変える近似です。

6距離比較は高速解像度で計算します。結果のタイルを押すと、その距離を現在選択している解像度で再計算します。「最初に目標へ届く距離」は試した6条件の中だけの結果です。厳密な最小距離探索ではありません。距離を増やすほど均一度が単調に良くなるとは限りません。

## 保存

「設定を保存」：型番と手動上書き値を含む全条件をJSON（schemaVersion 2）に保存します。「設定を開く」で復元できます。
円筒モード・内径・軸長・片側テープ長・方向も保存します。円筒入力は平面の輪郭・X/Y座標やテープ接続へ変換せず、同じJSONに保持します。形状モードを持たない旧JSONは「平面」として読み込みます。
旧schemaVersion 1も読み込めます。テープ幅を持たない旧設定（設定内の `version: 1`）では、従来の描画幅であるLED代表外形幅＋2 mmを引き継ぎます。新規設定の8 mmへ一律に変換しません。この値も実物の幅を保証するものではないため、使用するテープに合わせて調整してください。型番のない旧パッケージ設定は「カスタム・旧設定」として数値を保持し、外形だけで実在する型番へ割り当てません。
型番が保存されていても、明示されたRGB光度は読み込み時に保持します。型番初期値と異なる光度は「手動上書き」と表示します。旧設定の213 / 715 / 72 mcdも自動では変更しません。新しい型番値を使う場合は「型番の初期値に戻す」を押してください。

「画像を書き出す」：現在の仕上がりと、距離または円筒寸法・材料・LED・露出条件を付記したPNGです。平面では光量マップや配置タブを選択中でも仕上がり画像を書き出します。円筒の「LED配置」タブでは断面・側面図を書き出します。

「光量データCSVを保存」：各格子点の座標、評価対象かどうか、RGB別輝度、合計輝度、入射照度です。平面はX/Y、円筒は円周角度と軸方向の座標を使います。露出や画面の階調処理は含みません。

「比較基準に保存」：このページを開いている間だけ、計算済みの条件と結果を保持します。A/Bには現在の露出を共通適用します。ページを閉じると比較基準は失われます。

最後の設定は、利用可能な環境では同じブラウザのlocalStorageにも保存します。禁止された環境でもアプリは動作します。重要な設定はJSONで保存してください。入力・計算結果の自動的な外部送信はありません。ヘルプ内の資料リンクを開く操作は別途外部サイトへ移動します。

## 現時点の対象外

テープの曲げ半径、切断単位、コネクタ、電線の取り回し・各本間の自動配線、円筒以外の任意の曲面や傾いた板、STL/STEP形状、導光板、LED封止レンズ、側壁・背面の反射、障害物、屈折、多重散乱の厳密計算、材料の分光透過、カメラや人の視覚特性は対象外です。内部にじみが大きい複雑輪郭では、ガウス近似が切り欠きをまたぐなどの誤差も生じます。

特に透明・弱拡散材、極端な近距離、格子より小さな発光面では誤差が大きくなります。解像度警告に注意してください。最終的な寸法・材料・LEDの選定は実物で確認してください。

計算式、実測校正の手順、基礎資料は `MODEL.md` とアプリ内ヘルプを参照してください。
