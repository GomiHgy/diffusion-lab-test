# Diffusion Lab の計算モデル

## 1. モデルの位置づけ

本アプリは、正面観察する平行なLED面・拡散板に限定したRGB測光近似です。経路追跡による厳密な分光・体積散乱シミュレータではありません。与えられた仮定の中での光量分布を計算します。プリセットは実測校正していません。

材料の透過率は種類や板厚に依存し、散乱には角度分布も必要です。ARGBだけではこれらを定められません。参考資料：

- PLEXIGLAS, Light transmission: https://www.plexiglas.de/en/service/product-info/light-transmission
- PLEXIGLAS LED: https://www.plexiglas.de/en/products/plexiglas/plexiglas-led
- PBRT 4e, Phase Functions: https://www.pbr-book.org/4ed/Volume_Scattering/Phase_Functions

これらは基礎事項の参考であり、本アプリの材料値や光学近似をメーカーが認証したという意味ではありません。

## 2. 幾何と光源

座標はmm単位、原点は板の中央、x右向き、y下向きです。LED発光面を z=0、拡散板の入射側を z=d とします。d はユーザー入力の距離です。厚さは内部拡散幅に用いますが、厚さ方向の屈折経路・厳密な内部伝搬は計算しません。

SVG輪郭は全path要素の塗り領域の和集合です。各パスのnonzero/evenodd規則で穴を判定し、重なりの内部線を除いた境界から評価領域の端を求めます。曲線は細かな線分へ近似し、変換後の外接範囲を指定した幅・高さへ対応づけます。SVGの線幅・マスク・クリッピングや実寸は計算に含めません。SVGパスの文法と塗り規則の参考：[W3C SVG Paths](https://www.w3.org/TR/SVG/paths.html)、[W3C SVG Painting](https://www.w3.org/TR/SVG/painting.html)。

### テープの占有形状と連続した輪郭内判定

テープ幅 `tapeWidth` は0.1〜100 mmで入力する基板の幅です。新規設定の8 mmは比較用の仮値で、LED型番の仕様ではありません。幅がない旧設定内の `version: 1` は、旧描画幅の `packageSize + 2 mm` を引き継ぎます。型番選択・型番初期値への復元はテープ幅を保持します。幅は幾何判定と描画に使い、光度や有効発光面を幅から補正しません。

各LED中心の周りに、LEDの向きで回転したテープ幅×テープ幅の基板端部と、代表外形幅 `packageSize` × `packageSize` のLED正方形を置きます。隣接するLED中心はテープ幅の長方形ブリッジで接続します。長さゼロのブリッジは作りません。幅を持つこれらの占有形状を2D・3D描画と輪郭内判定で共用します。LED中心やパッケージ幅だけの検証ではありません。

多角形とSVGは、占有する各凸矩形の全頂点・重心が塗り領域にあり、実境界の線分が矩形の厳密な内部へ進入しないことを連続的に判定します。境界への接触は小さな数値許容差内で認めます。矩形が穴全体を覆う場合も、その穴の境界が内部へ入るため不適合になります。SVGには各パスの和集合の真の境界を使い、重なりの内部線や別パスで埋められた穴は障害にしません。曲線自体はSVG取り込み時の線分近似であり、元のベジェ曲線を厳密に判定する方式ではありません。

長方形・角丸・楕円の外側は凸なので、占有矩形の全頂点から連続包含を判定します。円環・楕円環の穴は、矩形を穴の長短半径で正規化し、原点と矩形の最短距離から解析的に交差を求めます。疎な点サンプルで切り欠き・穴を探索する方式ではありません。追加の距離余白を判定する内部APIでは、多角形・SVGは辺間距離を使い、楕円・円環は最短半径に基づく一様縮小・穴の一様拡大を使います。後者は安全側の判定で、細長い楕円では実際の等距離オフセットより保守的です。

並列・グリッド・円周・外周の自動配置は元の接続順をたどり、占有形状が収まらないLED候補や、輪郭を跨ぐブリッジで別のテープへ分割します。無効候補を除いた前後を再接続して切り欠き・穴を跨ぐことはありません。最終本数と分割箇所数を表示します。指定した並列本数と分割後の本数が異なる場合は明確にエラーを示し、本数の自動設定または手動配置へのコピー・調整を案内します。

SVG・多角形の外周候補は境界の局所法線とミターで内側へオフセットします。鋭い折り返しのミター長は制限し、生成した占有形状を再検証して収まらない部分を分割します。厳密なCADのブーリアン演算による等距離オフセットではありません。ユーザー指定の折れ線経路は、元の折れ線と密度でサンプルしたLED間のブリッジの両方を検証し、不適合なら自動分割せず適用を拒否します。

手動操作では移動・回転・整列・複製の対象群を幅込みで検証し、不適合なら操作全体を反映しません。旧保存配置や後からの輪郭・寸法・幅変更で不適合になった手動群は、座標と接続を保持します。2Dでその基板を赤く示し、群全体のLEDを光学計算から除外します。群内の一部だけを除いて新たな接続を作ることはありません。3Dは計算対象の適合群だけを描きます。

基板形状は模式的な面形状です。実物の曲げ半径、切断単位、コネクタ、電線の取り回しはモデル化せず、分割した各本間の電線接続も自動追加しません。取り付けや電気的な接続可能性は別途確認が必要です。

各LEDの各色について、正面光度 I0 [cd] と配光を与えます。入力 mcd は1/1,000してcdに変換します。

```
I(θ) = I0 × cos(θ)^m
m = −ln(2) / ln(cos(θ_full / 2))
```

θ_full は正面から両側を合わせた、光度が半分になる角度の全幅です。120°ならm=1となります。

型番選択では採用データシートのRGB正面光度を設定します。WS2812BはR / G / B = 400 / 1150 / 250 mcd（16 mA表のレンジ中心）、WS2812B-MINIは310 / 780 / 215 mcd（12 mA表の典型値）、WS2812C-2020は80 / 270 / 70 mcd（5 mA表の典型値）、SK6812は397.5 / 1045 / 240 mcd、SK6812-MINIは397.5 / 1045 / 292.5 mcd（いずれも12 mA表のレンジ中心）です。レンジ中心はメーカーの典型値ではなくモデル代表値です。元の範囲・採用版・ページは [LEDの仕様と近似](LED_SPECS.md) を参照してください。

光学表には光度測定時の電源電圧・温度・PWMデューティー・入力コードが明記されていません。別の電気特性表や寿命試験の条件を転用しません。採用光度を出力100%のモデル基準として、点灯パターンと出力%を一度だけ乗じます。型番選択・初期値への復元では外形・発光幅・角度・RGB光度を更新し、出力%とテープ幅は保持します。保存済み設定の明示光度は読み込み時に保持し、初期値と異なる場合は手動上書きとして表示します。

SK6812-012のp.3にはRGB同時点灯に70%の条件があるため、資料説明と計算結果の警告で示します。アプリは出力を強制変更したり、追加の70%係数を掛けたりしません。旧設定や手動入力の再現を保持し、必要な出力%はユーザーが指定します。

外形サイズと発光面は別です。型番別の参照資料と光学値の根拠は [LEDの仕様と近似](LED_SPECS.md) に記載しています。
WS2812B / WS2812B-MINI は機械図の開口を円形とみなし、面積が等しい正方形幅 `d × √π / 2` に置き換えます。これは開口を均一な有限光源として扱うモデル上の近似であり、実際のダイの発光幅ではありません。ほかの3種類は発光面寸法が資料にないため、明示した比較用の仮定を使います。
SK6812 / SK6812-MINI は資料の50%光度における全幅120°から `m=1` を求めます。Worldsemiの3種類は採用資料に角度の記載がないため全幅120°を仮定します。外形や開口の寸法から配光の角度を求めることはできません。

面光源は有効発光幅を持つ正方形で、各色のI0を面内で均等に分配します。各辺のサンプル数は格子の細かさに応じて3〜24点です。面要素を格子へ双線形に配分してから畳み込みます。この格子配分自体による小さな数値的平滑化も含まれます。

RGB分離を有効にすると、各色の有効幅は指定幅の0.43倍となり、中心を指定幅に対して次の比でずらします。

```
R = (−0.23, −0.14)
G = (+0.23, −0.14)
B = ( 0.00, +0.24)
```

これはチャンネル分離の効果を見るための仮定で、実在するパッケージのダイ配置を転記したものではありません。LED経路に応じて発光面を面内回転させます。

### 光源の推定光束

画面の光束表示は、上の配光を前方半球へ積分したモデル値です。

```text
Φ_c = ∫[0〜2π] ∫[0〜π/2] I0,c × cos(θ)^m × sin(θ) dθ dφ
    = 2π × I0,c / (m + 1)
Φ_RGB白・LED1個 = (Φ_R + Φ_G + Φ_B) × 出力% / 100
```

`I0,c`をcdで与えると`Φ`はlmです。各色の入力光度は既に測光量なので、光束を合計するときにsRGBのY係数を重ねて掛けません。画面は現在の明示光度・角度・出力%でLED1個のRGB白点灯を示し、現在の点灯パターンや全LEDの合計は求めません。露出や材料の透過率も掛けません。型番初期値の角度120°では`m=1`であり、RGB全点灯の1個当たりの100%基準光束は`π × (mcdR + mcdG + mcdB) / 1000`です。

採用資料は光度mcdを記載し、公称の光束lmは記載していません。この積分値をメーカー仕様や実測値とは扱いません。SK6812の100%基準は約5.286 lm、70%へ設定した場合の参考は約3.70 lmです。RGB同時点灯条件を満たすことや、100%時の実製品の光束を保証する値ではありません。光度レンジ・公差・配光の個体差は自動伝播せず、Worldsemiの角度には比較用の仮定も含まれます。

推定光束は拡散板に入射する前の光源の値です。有限な板が受け取る光束や、材料から出る光束はこの表示と異なります。板の面積・距離・光の分布・透過条件で変わる平均輝度cd/m²は、後述の入射照度と拡散板モデルから求めます。

## 3. 入射照度

光源から点までの距離をr、光源法線と受光面法線に対する角度をθとします。平行面なので両方の余弦因子を含めます。

```
E_c(x,y) = Σ I0,c × cos(θ)^(m+1) / r²
```

mm座標で計算するカーネルは次です。

```
K(Δx,Δy) = 10^6 × d^(m+1) /
           (Δx² + Δy² + d²)^((m+3)/2)
```

10^6はmm²からm²への換算です。I0がcdなら、Eはluxとなります。逆二乗則と受光面の余弦は、次の基礎に基づきます。

- PBRT 4e, Point Lights: https://www.pbr-book.org/4ed/Light_Sources/Point_Lights
- PBRT 4e, Diffuse Reflection: https://www.pbr-book.org/4ed/Reflection_Models/Diffuse_Reflection

RGBごとの光源分布とカーネルを、各軸を少なくとも2倍にゼロ詰めしたFFTで畳み込みます。反対側から光が回り込む循環畳み込みを避けています。負の微小な丸め誤差はゼロに切り上げます。

格子は長辺160 / 288 / 448点です。短辺は縦横比に応じた点数ですが、最低16点です。極端な縦横比ではx/yの物理格子間隔が異なります。格子間隔が距離の半分より大きい場合には警告します。

## 4. 拡散板

材料の入射照度を輪郭でマスクし、標準偏差σの分離ガウスフィルタを適用します。

```
σ [mm] = 厚さ [mm] × 内部にじみ係数
```

ガウスは±3σで打ち切って正規化します。輪郭外はゼロです。端でフィルタを再正規化せず、板から逃げる分を残します。最後に出射結果も輪郭でマスクします。切り欠きや穴の中を通る内部伝搬経路は追跡していません。そのため大きなσと複雑な輪郭の組合せでは、輪郭をまたぐ非物理的な混色が起こりえます。

Hは独自の「拡散成分比」です。全光をLambertian拡散と正面直進透過に分け、次のように合成します。

```
L_c = T × tint_c × [H × Gσ(E_c) / π + (1−H) × Ldirect,c]
```

T は入力厚さでの、色フィルタ適用前の透過率です。RGBフィルタを掛けると、実効透過率は色ごとにさらに低くなります。プリセットのTとHはいずれも仮定です。Tを厚さから自動計算するBeer–Lambert則は実装していません。

直接成分は、正面から平行投影で見た発光面の輝度を I0 / 面積で近似します。距離による放射輝度の不変性を意識した構成ですが、レンズ・屈折・視差・視距離・像形成は再現していません。

**Hは ASTM D1003などで定義されたヘイズではありません。** 実際のヘイズは測定角度に関係する量で、Lambertian成分比と同一視できません。Hに製品のヘイズ値を無条件で代入しても校正にはなりません。

## 5. ARGBと表示色

Aは8bitの「着色補間係数」としてのみ使います。

```
a = AA / 255
tint = (1−a) + a × sRGB_to_linear(RGB)
```

白を無彩色フィルタ、黒を吸収フィルタとするRGB近似です。実物の着色アクリルの分光透過曲線に一致するとは限りません。

各色の入力光度は測光量です。各色の出射輝度を理想sRGBのY係数 `[0.2126, 0.7152, 0.0722]` で除し、表示チャンネルの相対輝度に変換します。実LEDのピーク波長・スペクトル・CIE色度は扱っていません。

```
linear_display_c = L_c / Y_c × 2^EV / whiteLevel
```

whiteLevelの初期値は1,000です。圧縮モードは `1−exp(−linear_display_c)`、線形モードは0〜1でクリップし、その後sRGBに符号化します。圧縮モードは高輝度で彩度も変化します。ディスプレイ上の絶対cd/m²に校正された表示ではありません。

周囲光は材料フィルタを色として使った表示専用のLambertian近似です。材料の実際の反射率を測定したモデルではありません。照度・輝度の評価値には周囲光を含めません。

## 6. 評価値

線形のRGB輝度を合算して集計します。指定した端の領域は評価から除き、表示そのものは切り落としません。

- 平均、最小、最大、P5、P95。
- 均一度：P5/P95。P95がほぼゼロなら未定義。
- 内部診断値：最小/平均、標準偏差/平均。
- 中央水平断面のRGB別・合計輝度。

P5/P95は本アプリの比較指標で、業界標準の合否判定ではありません。色差を評価していないため、輝度が一定でも色が混ざっているとは限りません。露出、階調処理、表示用周囲光はこれらの統計を変えません。

## 7. 実物へ寄せるための校正

最初に、対象LEDの正確な型番、テープ基板の実測幅・密度、駆動条件、RGB正面光度と配光、拡散材の品番・厚さ・透過率を確認します。データが不明な項目をサイズやARGBだけから確定しないことが重要です。

実物比較では、LEDの出力と周囲光を一定にし、拡散板までの距離を複数段階で変えます。写真を使う場合はカメラの露出・ホワイトバランス・撮影位置を固定し、白飛びを避けます。一般的なJPEG画像は線形の測光値ではないため、その画素値をそのままluxやcd/m²とは扱えません。

まずRGB各色と白点灯で、距離別の分布を比較します。光度は全体の光量、配光は距離に応じた広がり、有効発光幅は近距離の粒の大きさ、σは材料内の局所的なにじみを主に調整するためのパラメータです。ただし互いに影響し、複数の組合せが似た結果を生むため、単一写真からの一意な同定はしません。

校正に用いていない距離・色・配置でも予測が合うかを確認します。それでも、曲面・反射壁・導光などモデル外の現象が支配的な構造にそのまま外挿することはできません。

## 8. 技術上の注意

主計算はWeb Workerで行い、変更が重なったときは待ち行列を最新1件だけにします。表示用の処理で物理フィールドを再正規化しません。距離別比較は別Workerで行い、光学条件の変更で取り消します。

大きな板に対する極小距離、小さな有効発光面、極端に大きいにじみ係数では、格子誤差または計算負荷が大きくなります。有限格子・有限サンプリング・近似材料モデルの誤差があるため、単体テストに合格していても実測精度を保証するものではありません。


## 9. テープ編集・3D・時間演出

テープの本数変更、回転、整列は接続されたLED群を一括で編集します。回転中心はLED中心の平均座標、入力角度は先頭LEDの向きです。整列はテープ端部・回転した代表パッケージ正方形・幅のあるブリッジ全体の外接範囲と板寸法・余白を使い、全体整列では全テープを同量だけ平行移動します。連続した輪郭内検証で失敗すると一括操作を反映せず、座標と接続を保持します。複製時の空き場所も同じ占有形状の外接範囲で判定するため、凹形では実際に入る配置を断る場合があります。曲げ半径・コネクタ・配線の衝突まで厳密に計算するCADではありません。

3DはCanvasの遠近投影です。LED発光面をz=0、拡散板裏面をz=gap、表面をz=gap+thicknessとし、ベース上面とテープ底面をz=−1.2 mm、テープ上面とパッケージ底面をz=−1 mm、LEDパッケージ上面と発光面をz=0として模式化します。基板とパッケージの側面を描き、現在のテープ幅で接触した設置状態を表示します。基板・LED占有形状は輪郭内判定と共用し、不適合な手動群は表示しません。光学計算の正面画像を三角形メッシュで表面へ貼り付け、板の側面とベース・パッケージは説明用の色で描きます。ベース・LEDの描画厚さは製品仕様ではありません。輪郭は光学計算と共用し、SVGではパスの和集合の実境界を使います。カメラの変更は計算された測光フィールドを変えません。斜め配光・反射・屈折の光線追跡は行いません。

動くRGB演出は周期位相からPWMを作り、既存の光源配置・配光・材料モデルへ入力します。出力倍率はRGB値へ一度だけ適用し、sRGB入力モードなら線形化してから倍率をかけます。24等分の位相を長辺160点で求解し、隣接フレームの線形輝度・照度・LED出力を補間します。この光学モデルは入力光源強度について線形なので、補間はPWMを線形補間した光源に対応します。連続演出の非線形な色変化自体には時間サンプリング誤差が残ります。

平均・均一度・中央断面は補間後の線形フィールドから各表示フレームで更新します。停止時は現在位相のPWMを直接作り、選択解像度で求解します。停止後のCSV・PNG・比較基準には停止時の結果を使い、距離比較は同じ停止位相を6条件に使います。時間演出の実機LED送信・同期は実装していません。
