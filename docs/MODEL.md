# Diffusion Lab の計算モデル

## 1. モデルの位置づけ

本アプリは、正面観察する平行なLED面・拡散板に限定したRGB測光近似です。経路追跡による厳密な分光・体積散乱シミュレータではありません。与えられた仮定の中での光量分布を計算します。プリセットは実測校正していません。

材料の透過率は種類や板厚に依存し、散乱には角度分布も必要です。ARGBだけではこれらを定められません。参考資料：

- PLEXIGLAS, Light transmission: https://www.plexiglas.de/en/service/product-info/light-transmission
- PLEXIGLAS LED: https://www.plexiglas.de/en/products/plexiglas/plexiglas-led
- PBRT 4e, Phase Functions: https://www.pbr-book.org/4ed/Volume_Scattering/Phase_Functions

これらは基礎事項の参考であり、本アプリの材料値や光学近似をメーカーが認証したという意味ではありません。

## 2. 幾何と光源

座標はmm単位、原点は板の中央、x右向き、y下向きです。LED発光面を z=0、拡散板の入射側を z=d とします。d はユーザー入力の距離です。厚さは内部拡散幅に用いますが、厚さ方向の屈折経路・厳密な内部伝搬は計算しません。

各LEDの各色について、正面光度 I0 [cd] と配光を与えます。入力 mcd は1/1,000してcdに変換します。

```
I(θ) = I0 × cos(θ)^m
m = −ln(2) / ln(cos(θ_full / 2))
```

θ_full は正面から両側を合わせた、光度が半分になる角度の全幅です。120°ならm=1となります。

外形サイズと発光面は別です。面光源は有効発光幅を持つ正方形で、各色のI0を面内で均等に分配します。各辺のサンプル数は格子の細かさに応じて3〜24点です。面要素を格子へ双線形に配分してから畳み込みます。この格子配分自体による小さな数値的平滑化も含まれます。

RGB分離を有効にすると、各色の有効幅は指定幅の0.43倍となり、中心を指定幅に対して次の比でずらします。

```
R = (−0.23, −0.14)
G = (+0.23, −0.14)
B = ( 0.00, +0.24)
```

これはチャンネル分離の効果を見るための仮定で、実在するパッケージのダイ配置を転記したものではありません。LED経路に応じて発光面を面内回転させます。

## 3. 入射照度

光源から点までの距離をr、光源法線と受光面法線に対する角度をθとします。平行面なので両方の余弦因子を含めます。

```
E_c(x,y) = Σ I0,c × cos(θ)^(m+1) / r²
```

mm座標で計算するカーネルは次です。

```
K(Δx,Δy) = 10^6 × d^(m+1) /
           (Δx² + Δy² + d²)^((m+3)/2)
```

10^6はmm²からm²への換算です。I0がcdなら、Eはluxとなります。逆二乗則と受光面の余弦は、次の基礎に基づきます。

- PBRT 4e, Point Lights: https://www.pbr-book.org/4ed/Light_Sources/Point_Lights
- PBRT 4e, Diffuse Reflection: https://www.pbr-book.org/4ed/Reflection_Models/Diffuse_Reflection

RGBごとの光源分布とカーネルを、各軸を少なくとも2倍にゼロ詰めしたFFTで畳み込みます。反対側から光が回り込む循環畳み込みを避けています。負の微小な丸め誤差はゼロに切り上げます。

格子は長辺160 / 288 / 448点です。短辺は縦横比に応じた点数ですが、最低16点です。極端な縦横比ではx/yの物理格子間隔が異なります。格子間隔が距離の半分より大きい場合には警告します。

## 4. 拡散板

材料の入射照度を輪郭でマスクし、標準偏差σの分離ガウスフィルタを適用します。

```
σ [mm] = 厚さ [mm] × 内部にじみ係数
```

ガウスは±3σで打ち切って正規化します。輪郭外はゼロです。端でフィルタを再正規化せず、板から逃げる分を残します。最後に出射結果も輪郭でマスクします。切り欠きや穴の中を通る内部伝搬経路は追跡していません。そのため大きなσと複雑な輪郭の組合せでは、輪郭をまたぐ非物理的な混色が起こりえます。

Hは独自の「拡散成分比」です。全光をLambertian拡散と正面直進透過に分け、次のように合成します。

```
L_c = T × tint_c × [H × Gσ(E_c) / π + (1−H) × Ldirect,c]
```

T は入力厚さでの、色フィルタ適用前の透過率です。RGBフィルタを掛けると、実効透過率は色ごとにさらに低くなります。プリセットのTとHはいずれも仮定です。Tを厚さから自動計算するBeer–Lambert則は実装していません。

直接成分は、正面から平行投影で見た発光面の輝度を I0 / 面積で近似します。距離による放射輝度の不変性を意識した構成ですが、レンズ・屈折・視差・視距離・像形成は再現していません。

**Hは ASTM D1003などで定義されたヘイズではありません。** 実際のヘイズは測定角度に関係する量で、Lambertian成分比と同一視できません。Hに製品のヘイズ値を無条件で代入しても校正にはなりません。

## 5. ARGBと表示色

Aは8bitの「着色補間係数」としてのみ使います。

```
a = AA / 255
tint = (1−a) + a × sRGB_to_linear(RGB)
```

白を無彩色フィルタ、黒を吸収フィルタとするRGB近似です。実物の着色アクリルの分光透過曲線に一致するとは限りません。

各色の入力光度は測光量です。各色の出射輝度を理想sRGBのY係数 `[0.2126, 0.7152, 0.0722]` で除し、表示チャンネルの相対輝度に変換します。実LEDのピーク波長・スペクトル・CIE色度は扱っていません。

```
linear_display_c = L_c / Y_c × 2^EV / whiteLevel
```

whiteLevelの初期値は1,000です。圧縮モードは `1−exp(−linear_display_c)`、線形モードは0〜1でクリップし、その後sRGBに符号化します。圧縮モードは高輝度で彩度も変化します。ディスプレイ上の絶対cd/m²に校正された表示ではありません。

周囲光は材料フィルタを色として使った表示専用のLambertian近似です。材料の実際の反射率を測定したモデルではありません。照度・輝度の評価値には周囲光を含めません。

## 6. 評価値

線形のRGB輝度を合算して集計します。指定した端の領域は評価から除き、表示そのものは切り落としません。

- 平均、最小、最大、P5、P95。
- 均一度：P5/P95。P95がほぼゼロなら未定義。
- 内部診断値：最小/平均、標準偏差/平均。
- 中央水平断面のRGB別・合計輝度。

P5/P95は本アプリの比較指標で、業界標準の合否判定ではありません。色差を評価していないため、輝度が一定でも色が混ざっているとは限りません。露出、階調処理、表示用周囲光はこれらの統計を変えません。

## 7. 実物へ寄せるための校正

最初に、対象LEDの正確な型番、テープの密度、駆動条件、RGB正面光度と配光、拡散材の品番・厚さ・透過率を確認します。データが不明な項目をサイズやARGBだけから確定しないことが重要です。

実物比較では、LEDの出力と周囲光を一定にし、拡散板までの距離を複数段階で変えます。写真を使う場合はカメラの露出・ホワイトバランス・撮影位置を固定し、白飛びを避けます。一般的なJPEG画像は線形の測光値ではないため、その画素値をそのままluxやcd/m²とは扱えません。

まずRGB各色と白点灯で、距離別の分布を比較します。光度は全体の光量、配光は距離に応じた広がり、有効発光幅は近距離の粒の大きさ、σは材料内の局所的なにじみを主に調整するためのパラメータです。ただし互いに影響し、複数の組合せが似た結果を生むため、単一写真からの一意な同定はしません。

校正に用いていない距離・色・配置でも予測が合うかを確認します。それでも、曲面・反射壁・導光などモデル外の現象が支配的な構造にそのまま外挿することはできません。

## 8. 技術上の注意

主計算はWeb Workerで行い、変更が重なったときは待ち行列を最新1件だけにします。表示用の処理で物理フィールドを再正規化しません。距離別比較は別Workerで行い、光学条件の変更で取り消します。

大きな板に対する極小距離、小さな有効発光面、極端に大きいにじみ係数では、格子誤差または計算負荷が大きくなります。有限格子・有限サンプリング・近似材料モデルの誤差があるため、単体テストに合格していても実測精度を保証するものではありません。
