# LED型番と光源パラメータの根拠

Diffusion Labでは、フルカラーLEDの型番を選ぶと、参照資料に基づくRGB正面光度と外形寸法、モデル用の発光幅・発光角度を設定します。**光度（mcd）、光束（lm）、輝度（cd/m²）は別の量です。外形寸法、発光窓の寸法、光学的な有効発光幅も区別します。** データシートにない値は、製品仕様として確定せず、比較用の仮定として表示します。

資料の確認日：**2026-10-05**。下表は、その日に取得・確認した版を採用しています。メーカーが作成したデータシートを参照し、一部は代理店のミラーを使用しています。各製品の最新版や、別の製造ロット・派生型番の仕様を保証するものではありません。

### 画面に表示する推定光束

採用資料にメーカー公称の光束`lm`はありません。画面の推定光束は、正面光度と余弦べき乗配光を前方半球へ積分したモデル値です。

```text
I(θ) = I0 × cos(θ)^m
Φ = ∫ I(θ) dΩ = 2π × I0 / (m + 1)
I0 [cd] = Iv [mcd] / 1000
```

画面はRGB各色を合計し、現在の出力%を反映した**LED1個のRGB白点灯**の参考値を表示します。現在のパターンの点灯色や全LEDの合計ではありません。配光の全幅120°では`m = 1`のため`Φ = π × I0`です。RGB全点灯・モデル出力100%を基準にすると、1個あたりの参考値はWS2812B約5.65 lm、WS2812B-MINI約4.10 lm、WS2812C-2020約1.32 lm、SK6812約5.286 lm、SK6812-MINI約5.45 lmです。SK6812を出力70%へ設定した場合のモデル参考値は約3.70 lmです。**SK6812の100%値も70%値も、製品の保証光束ではありません。**

推定光束は拡散板に入射する前の光源値です。有限な板が受け取る光量や、材料通過後の光束・平均輝度を表すものではありません。距離・板の寸法・透過率で変わる平均輝度`cd/m²`とは別に読み取ってください。実際の配光曲線が余弦べき乗分布と異なる場合や、Worldsemiの仮定角度が実物と異なる場合は推定光束も変わります。

### 発光窓からの面積換算

モデルは幅`w`の正方形面光源を使用します。円形開口の寸法`d`から面積だけをそろえる換算は、次の式です。

```text
w² = π × (d / 2)²
w = d × √π / 2
```

WS2812Bでは、機械図の4.00 mmが直径指定ではないため、開口を円形とみなす仮定も含みます。WS2812B-MINIではΦ2.85 mmを使用します。計算は丸め前の値で行い、画面では小数第3位まで表示します。機械寸法の公差は計算結果の不確かさとして自動伝播しません。

**この換算で得られる幅は、実際のRGBダイの幅や、測定された光学的な有効発光幅ではありません。** 光は発光窓の全域から均一に出るとは限らず、RGBダイの位置、封止材、反射構造などで分布が変わります。SK6812系の図面には窓やRGBダイの模式図がありますが、その大きさ・配置距離の寸法線はありません。図面の見た目の比率から規格値を作ることはしていません。

発光窓の寸法がない3型番の1.1 / 2.8 / 1.9 mmは、旧モデルとの比較を続けるための仮定です。パッケージの外形から製品の有効発光幅を推定した値ではありません。正確な光学幅が必要な場合は、対象品の実測分布またはメーカーが提供する光学データに合わせて入力・校正してください。

### 発光角度からの配光近似

アプリの角度は、正面光度の50%になる方向を両側に合わせた**半値角の全幅**です。SK6812系には50%で120°という記載があり、この代表値を使用します。公差やRGB別の個体差を含む保証値としては扱いません。Worldsemiの上記3資料には採用できる半値角の値がないため、全幅120°を比較用に仮定します。外形寸法や発光窓の寸法から発光角度は算出できません。

計算には、半値角から次の配光モデルの指数`m`を求めて使用します。

```text
I(θ) = I0 × cos(θ)^m
m = −ln(2) / ln(cos(θ_full / 2))
```

全幅`θ_full = 120°`なら片側の半値角は60°、`m = 1`です。メーカーの配光曲線全体を再現するものではなく、同じ半値角を持つ余弦べき乗分布への近似です。RGB分離の幅比や配置も比較用の仮定であり、上記資料のダイ配置を転記したものではありません。計算モデル全体は[MODEL.md](MODEL.md)を参照してください。

## 入力・保存時の扱い

型番を選ぶと、上表の外形代表幅・発光幅・角度・RGB正面光度を設定します。**LED出力%は保持します。** 各色の光度は実際の製品・駆動条件に合わせて上書きできます。

発光幅・角度・RGB正面光度は手動で上書きできます。画面では「開口面積からの近似」「資料未記載・仮定」「資料の半値角」「資料のTyp値」「記載範囲の中点」「手動上書き」など、現在の値の根拠を示します。「型番の初期値に戻す」で選択中の型番の外形・幅・角度・RGB光度を再適用し、出力%は保持します。外形を独自に指定する場合はカスタムを選択します。

新しい設定JSONは`schemaVersion: 2`で保存し、版1・版2を読み込めます。保存された明示的なRGB光度は、型番が指定されていても読み込み時に保持し、型番初期値と異なる場合は「手動上書き」と表示します。型番を持たない旧設定はカスタムとして読み込み、入力範囲内の既存の発光幅・角度・RGB光度などの数値を保持します。旧設定の外形サイズから実在する型番へ自動で割り当てることはありません。旧比較光源の213 / 715 / 72 mcdが保存されている場合も、読み込みだけでは上表の値へ置き換えません。
